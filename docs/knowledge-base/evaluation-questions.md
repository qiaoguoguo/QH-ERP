# 系统操作知识库真实问题题集

本题集用于后续帮助中心和知识检索验收。每个问题必须能命中预期文章，答案不得超出当前系统能力。

| 编号 | 用户问题 | 预期命中文章 | 答案要点 | 禁止误答 |
|---|---|---|---|---|
| Q001 | 无法登录时应该先检查什么？ | `common-login-navigation` | 账号、密码、账号状态、是否未授权、未登录跳转 | 不要要求改数据库或绕过登录 |
| Q002 | 为什么我看不到某个菜单？ | `common-permission-menu-button` | 菜单受角色权限控制，无权限不展示或禁止访问 | 不要说所有登录用户都有业务菜单 |
| Q003 | 用户停用后还能登录吗？ | `common-account-users-roles` | 停用用户不可正常进入系统 | 不要说停用只影响显示 |
| Q004 | 权限改完为什么用户页面没变化？ | `common-account-users-roles` | 角色权限影响菜单和按钮，相关用户可能需重新登录 | 不要让用户直接改接口 |
| Q005 | 业务期间锁定后还能补业务单据吗？ | `common-business-periods` | 锁定期间内影响经营口径的写入会被拒绝，开放期间反向业务仍需按规则 | 不要建议绕过期间锁 |
| Q006 | 审批详情跳转业务单据后怎么回来？ | `common-approval-center` | 全局返回审批入口或返回上下文回到审批详情 | 不要说审批页会自动完成审批 |
| Q007 | 编码规则里的流水长度是什么意思？ | `master-coding-rules` | 流水长度是编号流水位数，不是下一流水号的业务数量 | 不要把超大数当合理长度 |
| Q008 | 物料导入模板为什么要中文表头和下拉？ | `material-import-export` | 中文表头提升可读性，枚举字段用中文下拉，解析端兼容中英文 | 不要让用户手填英文枚举 |
| Q009 | 停用物料会删除历史单据吗？ | `material-categories-items` | 不删除历史，影响后续业务选择 | 不要说停用等于删除 |
| Q010 | BOM 草稿导入能直接发布 BOM 吗？ | `bom-draft-basic` | 当前导入只处理草稿或更新草稿，发布/启用仍按页面和权限 | 不要写成导入即生效 |
| Q011 | 库存余额里的可承诺量等于库存现货吗？ | `inventory-balances-availability` | 可承诺量是合格现存扣除占用预留等后的参考口径 | 不要把采购在途当现货 |
| Q012 | 冻结库存能销售出库或领料吗？ | `quality-inspections-status` | 冻结库存不可承诺，不参与出库、领料、补料 | 不要说冻结只是标签 |
| Q013 | 仓库调拨会生成哪些库存变化？ | `inventory-warehouse-transfer` | 确认后从调出仓扣减、调入仓增加 | 不要说只改仓库名称 |
| Q014 | 采购请购审批通过后下一步是什么？ | `procurement-requisition` | 可进入询价比价，根据请购来源生成询价和后续选价 | 不要直接跳到入库 |
| Q015 | 新建询价时为什么没有报价输入？ | `procurement-inquiry-quotation` | 询价单先确定采购需求和邀请供应商，报价在供应商报价列表录入或导入 | 不要说询价创建必须填报价 |
| Q016 | 供应商报价只填未税价还是含税价？ | `procurement-inquiry-quotation` | 税率、未税单价、含税单价应能互相换算，至少录入一个价格口径 | 不要要求重复手工算两遍 |
| Q017 | 非最低选价原因是什么意思？ | `procurement-selection-reason` | 选择非最低报价时说明质量、交期、资质等业务原因 | 不要把默认短横线解释成用户选择 |
| Q018 | 选价后怎么生成价格协议？ | `procurement-price-agreement` | 从已选报价生成协议，报价信息应自动带入，提交审批后生效 | 不要让用户重新手填所有报价事实 |
| Q019 | 价格协议审批通过后采购订单价格从哪里来？ | `procurement-price-agreement` | 生效价格协议可作为采购订单价格来源 | 不要说协议未审批也能作为正式来源 |
| Q020 | 采购订单列表的履约进度怎么看？ | `procurement-orders` | 看已入库/总量、未入库、在途和计划到货 | 不要显示技术字段替代业务语义 |
| Q021 | 普通采购订单为什么不显示审批状态？ | `procurement-orders` | 普通订单不默认审批，只有例外审批进入流程时展示审批状态 | 不要把未提交审批作为普通状态展示 |
| Q022 | 采购入库会影响库存吗？ | `procurement-receipts` | 确认入库后形成库存入库和后续应付来源 | 不要说只是记录到货 |
| Q023 | 采购退货会影响哪些数据？ | `procurement-returns` | 影响库存出库、采购退货记录和应付/结算来源 | 不要忽略库存影响 |
| Q024 | 销售报价审批通过后下一步是什么？ | `sales-quotes` | 可作为销售合同或订单的价格/商务依据 | 不要说报价通过自动发货 |
| Q025 | 销售订单确认后会产生什么？ | `sales-orders` | 形成有效销售需求、交付计划、预留和后续出库基础 | 不要说确认后直接产生发票 |
| Q026 | 信用额度不够为什么不能确认销售订单？ | `sales-credit-profiles` | 信用控制阻断时需按信用例外审批处理 | 不要建议绕过信用检查 |
| Q027 | 销售短交关闭是什么意思？ | `sales-orders` | 未全部交付时按审批关闭剩余交付需求 | 不要说等同取消已执行出库 |
| Q028 | 订单缺料分析是不是完整 MRP？ | `planning-material-requirements` | 当前用于订单缺料分析，不等同完整 MRP 或复杂 ATP | 不要扩展成未实现计划系统 |
| Q029 | 生产工单领料从哪里进入？ | `production-material-issues` | 从生产工单详情进入领料页面，按工单和物料扣减库存 | 不要让用户直接改库存余额 |
| Q030 | 完工入库后物料质量状态是什么？ | `production-completion-receipts` | 按页面和质量规则进入库存，后续可由质量确认处理 | 不要默认全部合格 |
| Q031 | 外协执行当前覆盖哪些动作？ | `production-outsourcing` | 外协订单、外协发料、外协收货，按当前页面入口操作 | 不要写成完整委外结算平台 |
| Q032 | 项目成本调整需要审批吗？ | `cost-adjustments-variances` | 成本调整按权限和审批动作控制 | 不要允许无审批直接改已归集成本 |
| Q033 | 应收和收款是什么关系？ | `finance-ar-ap-overview` | 应收是来源台账，收款用于核销或更新结算状态 | 不要把收款等同自动开票 |
| Q034 | 采购发票匹配异常怎么办？ | `finance-invoices-expenses` | 根据匹配状态处理来源、金额、税额或候选差异 | 不要让用户手改来源事实 |
| Q035 | 凭证草稿就绪后会自动记账吗？ | `finance-settlement-voucher-drafts` | 仍需进入正式凭证或审批记账链路 | 不要说就绪等于已记账 |
| Q036 | 业务月结和财务结账有什么区别？ | `period-close-business-close` `financial-close-funds-tax` | 业务月结冻结经营快照，财务结账关闭会计期间 | 不要混用两个状态 |
| Q037 | 财务结账为什么被阻断？ | `financial-close-funds-tax` | 看前置检查、未完成凭证、银行/税务/损益状态 | 不要建议强制关闭 |
| Q038 | 报表数据为什么显示受限或不可用？ | `report-permissions-data-boundary` | 权限、来源、快照状态和完整性会影响展示 | 不要把受限金额显示为 0 |
| Q039 | 数据修复能直接改任意字段吗？ | `platform-data-repairs` | 只支持固定适配器白名单字段，需审批执行验证 | 不要说可以 SQL 修复 |
| Q040 | 历史导入能导入库存期初吗？ | `platform-history-imports` | 当前固定适配器不允许导入库存期初、成本层、正式凭证等 | 不要扩展成通用导入 |
| Q041 | 导入失败应该看哪里？ | `import-export-templates` | 查看任务中心、错误文件、行级错误和模板版本 | 不要让用户反复上传猜字段 |
| Q042 | 固定打印生成后在哪里下载？ | `common-messages-tasks` `platform-delivery-assets` | 任务中心查看状态和下载，过期后重新生成 | 不要绕过对象权限下载文件 |
| Q043 | 附件是不是业务凭证本身？ | `attachments-audit-source-chain` | 附件是快照或辅助材料，业务事实以后端单据为准 | 不要用附件替代审批或入库 |
| Q044 | 当前帮助中心会替我点提交吗？ | `platform-current-boundaries` | 不会，帮助中心和后续 AI 助手只读咨询和导航 | 不要承诺代操作 |
| Q045 | 为什么搜索错误文案也要命中文章？ | `import-export-templates` | 错误文案是用户排障入口，应对应处理建议 | 不要只返回空结果 |
| Q046 | 知识库管理里新增或编辑文章后还需要审核发布吗？ | `system-knowledge-management` | 管理员在知识库管理维护分类和文章，填写关键词、关联路由、权限说明和关联知识，保存后立即对帮助中心生效 | 不要说普通用户可维护、需要审核发布、会调用业务写接口或由 AI 自动代写发布 |
