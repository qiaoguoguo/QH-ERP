# 系统逻辑证据契约

## 索引格式

- `schemaVersion`：当前为 `1`。
- `generatorVersion`：生成器版本。
- `generatedAt`：生成时间，不参与稳定内容比对。
- `sourceDigest`：所有白名单源文件路径与文件摘要的联合 SHA-256。
- `sourceFiles`：相对仓库路径和文件 SHA-256。
- `evidence`：结构化证据列表。

## 单条证据

每条证据必须包含唯一键、类型、业务域、标题、摘要、关键词、来源路径、来源行号、可信度和证据 SHA-256。路由、HTTP 方法、权限码和代码符号按证据类型选填。

## 可信度

- `1.00`：数据库约束、显式权限、接口映射、枚举常量。
- `0.90`：显式路由、菜单、校验注解、错误码、测试行为。
- `0.75`：由赋值、分支或页面文本推导的状态流转和页面元素。

## 使用规则

- 代码证据用于回答“当前系统实际如何限制或流转”，人工文章用于回答“用户应如何操作”。
- 证据必须能回溯到当前激活快照中的来源文件和行号。
- 没有证据时必须说明知识不足，不得补造功能、字段、权限或状态。
- 代码证据不得直接通过前端接口返回；未来 AI 服务只能输出面向用户的归纳结果和必要的页面导航。
